# Wiki Assets

Store screenshots and other documentation images for the wiki in this folder.

Suggested naming style:

- `data-management-import-overview.png`
- `data-management-maintenance-backup.png`
- `data-management-danger-zone.png`
- `getting-started-overview.png`
- `sql-workspace-overview.png`
- `widgets-overview.png`
- `dashboard-overview.png`
- `settings-overview.png`

Use relative paths from wiki pages, for example:

```md
![SQL Workspace overview](assets/sql-workspace-overview.png)
```
